# Технический обзор · Support Service — API обращений в поддержку

Оценка для позиции Junior Python Developer / Integration Engineer. Основание — статический анализ исходников, сохранённых в Git на коммите `9de1c01`. Выводы о сценариях отказа требуют проверки в рабочем окружении.

## Сильные стороны

Простой API отделяет схемы от моделей БД, а запрос списка фильтруется по пользователю.

## Слабые стороны и архитектурные замечания

Сервис принимает идентификатор из заголовка, при этом Compose публикует порт. В конфигурации, доступной клиенту напрямую, заголовок можно задать вручную.

## Что проверить на демонстрации

Нужны управление статусом обращения и проверка границы доступа между шлюзом и сервисом.
